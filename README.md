# 📊 Workforce Management Forecast & Scheduling Tool

This repository contains an Excel-based **Workforce Management (WFM)** tool designed to help call centers forecast workload, validate staffing levels, and manage employee schedules efficiently.

---

## 🧾 Overview
The workbook provides a complete view of call demand, staffing capacity, and agent scheduling.  
It enables WFM teams to align resources with forecasted call volumes and identify overstaffing or understaffing periods.

---

## 📂 File Contents
**`New Microsoft Excel Worksheet.xlsx`** includes three key sheets:

1. **Call Arraivals** – Displays forecasted and historical call arrivals by time interval and weekday, including averages and percentage trends.  
2. **Schedule Validation** – Compares forecasted demand against scheduled capacity, showing where the team is over or under staffed.  
3. **Roster** – Maintains employee shift schedules, presence (P), and off days (OFF/WO).

---

## ⚙️ Key Features
- 📈 Call volume forecasting by 30-minute intervals  
- ✅ Schedule validation against expected arrivals  
- 👥 Visual tracking of agent availability and weekly off days  
- 💡 Data-driven insights for optimizing resource planning
